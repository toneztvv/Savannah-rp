# Savannah RP Website (Simplified)

Six clear categories — no more bouncing between random pages.

## Main navigation
1. **Home** — brand + category hub
2. **Play** — Discord, connect, new player guide
3. **City** — features, directory, media, news
4. **Apply** — role cards + one application form
5. **Store** — packages + custom order links
6. **Help** — FAQ, tickets, support, policies

**Rules** are linked from Play/Help (and a Home hub card).
